# KinoNepoisk

Расширение для браузера: открывает фильмы и сериалы с Кинопоиска на выбранном зеркале, умеет искать прямо из попапа и настраивать домен под себя.

Сейчас актуальная версия — **1.4.13**. Свежий архив всегда в [Releases](https://github.com/ggllch/KinoNepoisk/releases/latest).

## Как поставить

**Chrome, Edge, Яндекс.Браузер**

1. Скачай zip из релизов и распакуй.
2. Зайди на `chrome://extensions` (в Edge — `edge://extensions`).
3. Включи режим разработчика.
4. Нажми «Загрузить распакованное расширение» и укажи папку из архива.
5. Если обновляешь уже установленное — достаточно кнопки «Обновить» на карточке расширения.

**Firefox**

1. Открой `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выбери `manifest.json` из папки.

## Что внутри

- автозамена ссылок Кинопоиска или предложение перейти на зеркало;
- поиск с фильтрами и сортировкой;
- настройка домена, названия сайта и размера сетки результатов.

Если нужен нейтральный вариант без привязки к конкретному зеркалу — рядом лежит [HostShift](https://github.com/ggllch/HostShift).
